# 5. Tóm tắt kiến trúc (Architecture Summary)
- **Patterns**: N-Tier Architecture separating Frontend (Blazor WebAssembly/Server), Backend API, and Shared code (DTOs). The Backend utilizes the Unit of Work (UoW) and Repository pattern (e.g., _unitOfWork.VPPContext).
- **Auth Flow**: Uses JWT authentication. The authentication mechanism calls a stored procedure (sp_Authentication_Login), converts the result to Claims (sp_AuthenticationLogin_To_Claims), and validates via JwtBearer.
- **Stored Procedures (SPs)**: Heavy reliance on Stored Procedures for complex logic and fetching data. 
  - Dynamic SP execution is wrapped in BaseServices.SP and BaseServices.Query which use EF Core's FromSqlRaw("exec {0} @SpType={1}, @Param={2}"). 
  - Result sets are commonly mapped to a generic sp_ResDTO DTO class. 
  - Examples of frequently used SPs: sp_Authen, sp_Authentication_Login, sp_Authen_TabUser_UserList, sp_Authen_GetPermissionSinglePage.
